# Korona Stock History Exporter

This Python script connects to the Korona Studio API to retrieve and reconstruct historical inventory data for retail products. It calculates stock levels for a specified date by aggregating:

- Stock counts
- Stock adjustments
- Stock receipts
- Sales data

The final output is a formatted Excel file showing the calculated stock levels for each product.

## Features

- 🔍 Pulls historical inventory data from Korona Studio API
- 📊 Aggregates multiple data sources to reconstruct stock levels
- 📁 Exports results to Excel for easy analysis
- 📅 Supports querying by specific date

## 📁 Repository Contents

This repository includes the following files:

- `historicalInventory.py`  
  Main Python script that connects to the Korona Studio API, retrieves historical inventory data, calculates stock levels for a specified date, and exports the results to Excel.

- `inventory_log_hospitality_20240727.log`  
  Example log file from a script run in August 2025 for the target date July 27, 2024. It details all API calls made during execution, including endpoints accessed and response statuses. Useful for debugging and auditing.

- `inventory_snapshot_hospitality_20240727.xlsx`  
  Example Excel output generated by the script. Contains reconstructed inventory data for July 27, 2024, including product-level stock calculations.
